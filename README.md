# portfolio

Salih's portfolio site: a single static page (`index.html`), no build step.

## Deploy on Vercel

1. Import this repository in Vercel (Add New > Project).
2. Framework preset: **Other**. Leave the build command and output directory empty.
3. Deploy. Every push to `main` redeploys automatically.

## Edit

Everything is in `index.html`: styles at the top, content in the middle. Open it in a browser to preview.
